# Anonymous Message Bot (Telegram)

A Telegram bot that lets people send you anonymous messages through a unique, shareable link — perfect for feedback, questions, or confessions without revealing identity.

---

## ✨ Features

- **Personal anonymous link** for every user (share it anywhere)
- **Anonymous inbox**: receive text and media
- **Reply** to anonymous messages via inline buttons
- **Blocklist**: block unwanted senders, clear your blacklist anytime
- **Feedback channel**: users can send feedback to admin
- **Donations** (Telegram Stars / XTR) support flow (optional)

---

## 🧩 Tech Stack

- **Python 3.10+**
- **aiogram 3.x**
- **SQLite + SQLAlchemy (async)**
- **Redis** (FSM storage)
